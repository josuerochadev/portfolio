POEI Mainframe · Phase CICS

Flux Pseudo-Conversationnel

Chaque interaction SEND MAP libere la tache CICS. Le contexte est preserve dans la COMMAREA et restaure au RETURN TRANSID suivant.
01
> Lancement de la transaction
L'utilisateur tape le code transaction (ex: AFFI) dans le terminal 3270. CICS demarre le programme associe (PRGCLIA).
* EIBCALEN = 0 : premier passage, pas de COMMAREA EVALUATE TRUE WHEN EIBCALEN = 0 PERFORM 1000-PREMIER-PASSAGE
EIBCALEN = 0
02
> SEND MAP — Ecran vide
Le programme affiche l'ecran BMS vierge avec un message invitant a saisir un numero de compte.
EXEC CICS SEND MAP('MAPAFF') MAPSET('CLIAFF') ERASE END-EXEC
ecran affiche au terminal
03
> RETURN TRANSID + COMMAREA
La tache CICS est liberee. Le contexte (flag d'initialisation) est sauvegarde dans la COMMAREA. CICS sait quel TRANSID relancer a la prochaine frappe.
EXEC CICS RETURN TRANSID('AFFI') COMMAREA(WS-COMMAREA) LENGTH(LENGTH OF WS-COMMAREA) END-EXEC * -- Tache terminee, ressources liberees --
utilisateur saisit + ENTREE
Boucle pseudo-conv.
04
> RECEIVE MAP — Lecture saisie
CICS relance le programme. EIBCALEN > 0 indique un passage suivant. Le programme recoit les donnees saisies par l'utilisateur.
EXEC CICS RECEIVE MAP('MAPAFF') MAPSET('CLIAFF') RESP(WS-RESP) END-EXEC
RIDFLD(WS-NUMCPT)
05
> READ fichier VSAM
Recherche du client dans le fichier VSAM KSDS par cle primaire (NUM_COMPTE). Gestion des cas NORMAL, NOTFND et erreur.
EXEC CICS READ FILE('FCLIENT') INTO(ENR-CLIENT) RIDFLD(WS-NUMCPT) RESP(WS-RESP) END-EXEC
DFHRESP(NORMAL)
06
> SEND MAP — Donnees client
Les champs du client sont transferes dans la MAP et affiches. Optimisation DATAONLY pour ne renvoyer que les donnees.
MOVE CLI-NOM TO NOMO MOVE CLI-SOLDE TO SOLDEO MOVE CLI-POSITION TO POSITO EXEC CICS SEND MAP('MAPAFF') MAPSET('CLIAFF') END-EXEC
RETURN TRANSID + COMMAREA
07
> PF3 — Fin de transaction
L'utilisateur appuie sur PF3. Le programme detecte DFHPF3 via EIBAID, affiche un message de fin et fait un RETURN sans TRANSID — la boucle est rompue.
WHEN EIBAID = DFHPF3 PERFORM 9000-FIN-PROGRAMME * Dans 9000-FIN-PROGRAMME : EXEC CICS SEND TEXT FROM(WS-MSG-FIN) ERASE END-EXEC EXEC CICS RETURN * sans TRANSID END-EXEC

Concepts cles
COMMAREA
Zone de communication entre passages. Sauvee par CICS au RETURN, restauree au passage suivant. Contient le flag d'initialisation et les donnees de contexte.
Pseudo-conversationnel
La tache CICS est liberee entre chaque interaction. Zero ressource consommee pendant la frappe — essentiel pour supporter des milliers d'utilisateurs simultanes.
FSET + DATAONLY
FSET marque les champs comme modifies (MDT) dans le BMS pour les renvoyer automatiquement. DATAONLY evite de retransmettre la structure MAP.
CURSOR dynamique
En cas d'erreur de saisie, le curseur est positionne sur le champ fautif via MOVE -1 TO NUMCPTL suivi de SEND MAP ... CURSOR.
