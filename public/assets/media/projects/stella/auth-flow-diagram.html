Flux Auth — JWT + CSRF

🔑 Double protection : Tokens
Trois tokens complementaires pour une securite multicouche
Access Token (JWT)
Cookie accessToken httpOnly
Expire : 15 min
Signe avec JWT_SECRET
Scope : /api
Refresh Token (JWT)
Cookie refreshToken httpOnly
Expire : 7 jours
Persiste en DB (RefreshToken)
Rotation a chaque refresh
CSRF Token (JWT)
Cookie XSRF-TOKEN (lisible JS)
Expire : 1 heure
Header X-CSRF-Token requis
Double validation : JWT + session
Flux de connexion
👤 1. Client — Login
1 L'utilisateur saisit email + mot de passe
2 POST /api/auth/login avec withCredentials: true
authLimiter: 5 req / 15 min
⚙️ 2. Serveur — Auth Controller
1 Validation Joi du schema loginSchema
2 Recherche utilisateur via userRepository.findByEmail()
3 Comparaison bcrypt — auto-rehash si rounds obsolete
4 Generation paire { accessToken, refreshToken }
5 Revocation des anciens refresh tokens, sauvegarde nouveau en DB
6 Set cookies httpOnly + retourne { success, userId, role }
Set-Cookie: accessToken, refreshToken (httpOnly) Set-Cookie: XSRF-TOKEN (lisible)
✅ 3. Client — Session active
1 AuthContext passe a isAuthenticated = true
2 Fetch panier + wishlist en parallele
3 Intercepteur Axios lit XSRF-TOKEN cookie et injecte X-CSRF-Token header
Requete protegee (mutation)
🚀 Requete depuis le client
Exemple : POST /api/cart/add
Cookie: accessToken (auto) Header: X-CSRF-Token withCredentials: true
🛡️ Chaine de middleware
1 authenticateUser — decode JWT depuis cookie accessToken (ou Bearer header fallback)
2 requireAuth — bloque si req.user === null (401)
3 csrfValidate — verifie signature JWT du token CSRF + match avec req.session.csrfToken
4 validate(schema) — validation Joi du body/params
req.user disponible
✅ Controller
Traitement de la requete avec l'utilisateur authentifie
Refresh & Logout
🔄 Refresh
POST /api/auth/refresh
1Lit cookie refreshToken
2Verifie en DB (non revoque, non expire) + JWT
3Genere nouvelle paire (rotation)
4Revoque ancien, sauvegarde nouveau
🚪 Logout
POST /api/auth/logout (requireAuth)
1Revoque le refresh token courant
2Revoque TOUS les tokens de l'utilisateur
3Clear cookies accessToken + refreshToken
4Client : reset stores Zustand + redirect /auth
